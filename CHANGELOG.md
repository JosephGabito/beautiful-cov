# Changelog

All notable changes to `beautiful-cov` are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.1.0b2] - 2026-07-25

### Changed

- Set the README wordmark to a stable GitHub-compatible 400-pixel width.
- Replaced screenshot-generated image text with a descriptive product alt.

### Maintenance

- Excluded the private local `__workspace__/` directory from Git.

## [0.1.0b1] - 2026-07-25

### Added

- Published the first public beta of the `beautiful-cov` command-line tool.
- Added compact project and directory coverage dashboards.
- Added browsable Python source views with covered, missing, and excluded lines.
- Added exact pytest test-context attribution for covered source lines.
- Added portable static reports with bundled templates, styles, and scripts.
